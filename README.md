# e-plantShopping

**Project name:** Paradise Nursery – e-plantShopping

Paradise Nursery is an online plant shop built with React, Vite and Redux Toolkit by Ali Burak Sert. The repository name is `e-plantShopping`.

## Features
- Landing page with a background image, company name, company description (About Us) and a **Get Started** button
- Product listing page with 5 plant categories (6 plants each), each with a thumbnail, name, description and price
- **Add to Cart** buttons that add the plant to the Redux cart, disable themselves ("Added to Cart") and update the cart icon count
- Navbar on the product and cart pages with links to Home, Plants and Cart
- Shopping cart page with per-plant subtotal, total cart amount, increase/decrease/delete buttons, a **Continue Shopping** button and a **Checkout** button (shows a "Coming Soon" message)

## Run locally
```
npm install
npm run preview
```
